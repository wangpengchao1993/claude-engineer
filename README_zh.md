## 为什么选择这个仓库？

- **一站式参考** — 涵盖 Claude Code CLI、API、Agent SDK、MCP、Prompt 工程等所有内容。
- **即拿即用** — 提供 `CLAUDE.md`、Hooks、系统 Prompt、MCP 配置等模板，复制即可使用。
- **真实案例** — 可运行的代码示例，覆盖 Agent、Tool Use、流式处理和自动化工作流。
