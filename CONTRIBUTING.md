# Contributing to Claude Engineer

Thank you for your interest in contributing! / 感谢你的贡献！

## How to Contribute / 如何贡献

### Reporting Issues / 报告问题

- Use GitHub Issues for bug reports and suggestions
- Include clear descriptions and steps to reproduce

### Content Contributions / 内容贡献

We welcome:
- **Typo fixes** — Fix errors in existing content
- **New templates** — Add CLAUDE.md, hooks, or prompt templates
- **New guides** — Write tutorials on Claude usage
- **Resource links** — Add tools, articles, or videos to `awesome.md`
- **Translations** — Improve Chinese or English translations
- **Code examples** — Add runnable examples

### Submitting Changes / 提交修改

1. Fork the repository
2. Create a feature branch: `git checkout -b feat/your-feature`
3. Make your changes
4. Commit with a descriptive message
5. Push and create a Pull Request

### Content Guidelines / 内容准则

- **Accuracy**: Verify all commands and code examples work
- **Bilingual**: Include both English and Chinese where applicable
- **Practical**: Focus on real-world usage, not theory
- **Concise**: Keep explanations clear and to the point

### Code Style / 代码风格

- Markdown files: Use ATX headers (`#`), fenced code blocks
- Code examples: Include language identifiers in code blocks
- Links: Use relative paths for internal links
